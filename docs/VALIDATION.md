## 实板待验收

1. 加载CLP扩展版，UART打印四种SHAPES，连续32轮PASS，PCIe读回4 KiB匹配且诊断无错误；测试区已确认独占。
2. 验证多行、多列、K尾部和RVV输出尾段在实板正确；失败时按README采集数据和保留字段，不用中间断点暂停代替连续运行。
3. 最小链路通过后迁移模型数据布局、修正标量/RVV/AMU 缓存交接，再验证启动自测及 PCIe READY。
4. bus/zidane 对照候选框类别、置信度和坐标；随后在 host 验收视频、摄像头、录像、持续运行与实际吞吐。不设经验容差掩盖差异。

失败保留 `report.json`、`diagnostics.jsonl`、部署日志、终端文字日志及加载固件哈希，参照 [诊断说明](DIAGNOSTICS.md) 定位。
