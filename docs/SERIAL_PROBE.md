# UART 调试端口查找

UART 仅输出运行文字；模型输入、候选框和结构化诊断走 PCIe。工具在物理连接板卡的 Linux host 上运行，仅用 Python 标准库。

```bash
python3 yolo26_pc/serial_probe.py
python3 yolo26_pc/serial_probe.py --json
```

列出串口设备、USB 厂商/产品/序列号、稳定别名、权限、可见占用进程和锁文件。扫描不会打开串口、发送数据、删除锁或终止进程；没有占用记录不证明端口空闲，普通用户可能无法查看其他进程。

按接线或适配器序列号确认端口。必要时在无任务运行时比较 USB 插拔前后的列表；枚举成功本身不能证明该端口连接 N550。

在 minicom/PuTTY 中使用 **115200、8N1、关闭 RTS/CTS 和 XON/XOFF**，先打开终端再启动固件。可与 PCIe 客户端同时运行，同一串口只使用一个终端。需要保留文字时启用终端的会话日志。

没有打印时检查端口、权限、接线、UART 时钟/复位及固件启动。终端打开太晚可能错过启动信息，用 PCIe READY 或后续帧日志判断状态。固件不响应 HELLO/ping，不重发以前日志，也不通过 UART 接收任务。
