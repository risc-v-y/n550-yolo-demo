本轮 PCIe 视频集成检查因 WSL 未安装可选 NumPy/OpenCV 而跳过，未据此声称视频重新通过。此前合成视频两帧及 QEMU 15 帧结果是既有证据，不能替代更新后实板连续运行。

以上均为构建、本机或 QEMU 检查，**不构成真实 S2C 板卡的运行验收**。QEMU 不模拟 N550 非一致 DCache；模拟 PCIe/寄存器和替身推理不能证明现场传输、时序、模型数值及吞吐。

## 实板待验收

1. 核对固件哈希、DDR 独占、DCache、复位脚本目录和启动入口；先开 UART，按 `reset1.sh→pbcopy→reset.sh` 加载，确认日志、自测和 PCIe READY。
2. 验证加载失败确实保持复位，以及真实 RVV→AMU→RVV 缓存可见性/完成等待。
3. bus/zidane 推理对照原始候选框的类别、置信度和坐标，查看 SVG，不设经验容差掩盖差异。
4. host 具备 NumPy/OpenCV 和图形会话后，验收两帧视频、摄像头、录像、持续运行和实际吞吐；检查 UART 错误与详细节点日志。

失败保留 `report.json`、`diagnostics.jsonl`、部署日志、终端文字日志及加载固件哈希，参照 [诊断说明](DIAGNOSTICS.md) 定位。
